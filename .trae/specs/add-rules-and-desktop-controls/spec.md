# 规则、桌面功能与更新

## 为什么

用户需要查看当前内核实际使用的规则、按需刷新规则提供者，并通过托盘和全局快捷键操作应用。截图显示 Mihomo v1.19.34 的 Windows ZIP 下载后被判为缺少可执行文件，需要纠正归档识别。现有更新入口只针对 Mihomo，应用自身版本需要独立入口。

## 变更范围

新增规则页与规则提供者刷新、Windows 托盘、可配置的全局显示窗口快捷键，以及独立的 ClashYuka 更新检查。修复 Windows Mihomo ZIP 解包。规则和更新流程参考 Clash Verge Rev 的行为，沿用 ClashYuka 的原生页面和内核会话。

## 功能要求

### 规则与规则提供者

规则页按内核提供的顺序显示规则类型、匹配项和目标，支持搜索。内核未就绪、获取失败和规则为空分别显示。提供者区显示名称、类型、规则数量及内核提供的更新时间。用户可单独触发支持刷新的提供者，操作期间禁止重复请求，结果通过重读内核状态确认。失败时保留最近有效数据，提示重试。内核切换或退出后丢弃旧会话结果。

### 托盘与快捷键

Windows 托盘提供打开主窗口、切换系统代理意愿和退出。代理菜单同步现有状态与可用性。关闭到托盘由设置项启用，默认关闭，托盘不可用时确保主窗口可找回。托盘退出走正常关闭与代理恢复流程。全局快捷键默认关闭，由用户配置，注册失败明确提示，保留上一组仍有效的设置，退出时注销。

### 应用自身更新

设置页分别显示 ClashYuka 与 Mihomo 更新状态。用户可手动检查 ClashYuka 的官方发布，看到当前和可用版本。支持当前平台且有合适发布资产时，经用户操作前往官方发布页获取更新。仓库尚无已确认的分发安装器与签名发布链，本期交付检查和官方下载入口，应用内下载安装留待发布资产与签名链确定后实施。无发布源时显示不可用，失败可重试。

### Mihomo ZIP 解包

识别现有的 `mihomo.exe` 及经验证的官方 Windows 平台和版本命名。只将唯一、安全且匹配的可执行条目写入安装暂存目录。归档损坏、缺失或候选不唯一时报告具体错误并保留现有内核和设置。保留哈希校验、归档路径安全限制和版本分目录安装流程。用官方包清单或等价文件名的合成 ZIP 复现截图问题，记录实际验证覆盖。
