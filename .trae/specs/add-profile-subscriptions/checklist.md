# 验收清单

- [x] Profiles 无 Demo 数据；可导入本地 YAML、重命名、确认删除并在重启后恢复列表。原文件不被改写，内置及正在使用或选中的配置不能直接删除。
- [x] 可通过 HTTPS 添加订阅并手动刷新；可选定时刷新默认关闭，同一订阅不重复执行。失败、取消及关闭应用不会覆盖旧副本或留下迟到的 UI 更新。
- [x] 请求校验证书、禁止降级、限制体积并设有超时；日志、错误提示和运行监视记录不暴露订阅令牌或 API Secret。无 HTTPS 后端的平台明确显示限制。证书拒绝使用了本地自签 TLS；降级保护验证了实际 WinHTTP 请求使用的策略，未跑可信 TLS 重定向链。
- [x] 非法和不支持的配置以可理解的错误拒绝；生成运行副本不修改导入文件、不扩大监听范围、不启用 TUN。语法检查和真实内核校验在界面反馈中不混淆；首次启动的预检查拒绝通过进程替身验证。
- [x] 停机选择不启动内核；运行中切换须确认，仅在 API 就绪后更新当前运行配置；刷新当前配置不自动重启。
- [ ] 新配置预检查失败不停旧内核；若启动失败，尝试恢复原运行副本，回退失败可见。内置配置仍可手动选择，原系统代理恢复流程不回归。
- [ ] Windows Debug、Release 构建和全量 CTest 通过；记录 VS MCP 的构建、诊断与运行监视结果或已验证的回退方式。使用隔离数据目录实测关键流程，缺真实内核时明确列出未验证项。
- [x] 工作区原有系统代理改动保留；不引入其他功能，不生成 .sln 或 .vcxproj，不覆盖真实用户数据。
